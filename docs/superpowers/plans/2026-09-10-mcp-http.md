**Architecture:** Web Request/Response transport owns bounded MCP sessions; each session creates its own existing core. Node listener and Durable Object adapters reuse that transport. Worker validators are compiled at build time.
**Tech Stack:** TypeScript, Node HTTP, Ajv standalone, Cloudflare Workers/Durable Objects, official MCP SDK (test only).
